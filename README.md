# 🍎 TEACHERKIT — สุดยอดเครื่องมือสำหรับครู

ชุดเครื่องมือฟรีสำหรับครูไทย ใช้งานได้ทันทีบนเบราว์เซอร์ **ไม่ต้องสมัคร ไม่ต้องติดตั้ง ไม่มีโฆษณา**
ใช้ได้ทั้งบนคอมพิวเตอร์ โปรเจกเตอร์ แท็บเล็ต และมือถือ และใช้แบบออฟไลน์ได้หลังเปิดครั้งแรก

> 🔒 **ข้อมูลนักเรียนทั้งหมดเก็บไว้ในเครื่องของคุณเท่านั้น** (localStorage ของเบราว์เซอร์) ไม่มีการส่งข้อมูลขึ้นเซิร์ฟเวอร์ใด ๆ

## ✨ เครื่องมือ

| เครื่องมือ | ทำอะไรได้ |
|---|---|
| 🎯 **สุ่มชื่อนักเรียน** | สุ่มเรียกชื่อแบบมีลุ้น มีเสียง เลือก "ไม่ซ้ำคนเดิม" ได้ แสดงเต็มจอ กด Space เพื่อสุ่ม |
| 🧩 **แบ่งกลุ่มอัตโนมัติ** | แบ่งตามจำนวนกลุ่มหรือจำนวนคนต่อกลุ่ม แต่ละกลุ่มต่างกันไม่เกิน 1 คน คัดลอก/พิมพ์ได้ |
| ⏱️ **จับเวลา** | นับถอยหลังพร้อมเสียงเตือน และจับเวลาแบบนาฬิกาจับเวลา แสดงตัวเลขใหญ่เต็มจอ |
| ✅ **เช็คชื่อเข้าเรียน** | บันทึก มา/สาย/ลา/ขาด รายวัน สรุปทั้งภาคเรียน เตือนเมื่อเวลาเรียนต่ำกว่า 80% ส่งออก Excel |
| 📝 **คำนวณเกรด** | กำหนดช่องคะแนน (เก็บ/กลางภาค/ปลายภาค) ตัดเกรด 0–4 ตามเกณฑ์ (ปรับได้) ดูกราฟการกระจายเกรด ส่งออก Excel |
| 🏆 **กระดานคะแนนทีม** | เพิ่ม/ลดคะแนนทีมระหว่างเล่นเกม แสดงทีมที่นำ เต็มจอได้ |
| 🔊 **วัดระดับเสียงในห้อง** | ใช้ไมโครโฟนแสดงระดับเสียงแบบหน้ายิ้ม เตือนเมื่อเสียงดังเกินกำหนด |
| 🪑 **ผังที่นั่ง** | สุ่มหรือเรียงที่นั่งตามเลขที่ คลิกสลับที่ได้ พิมพ์ติดหน้าห้อง |
| 🎲 **ลูกเต๋า · เหรียญ · สุ่มเลข** | ทอยลูกเต๋าหลายลูก โยนหัว-ก้อย สุ่มเลขในช่วง (เช่น สุ่มเลขที่) แบบไม่ซ้ำได้ |
| 📚 **ติดตามการส่งงาน** | เช็คว่าใครส่ง/ส่งช้า/ยังไม่ส่ง ดูภาพรวมทุกงาน คัดลอกรายชื่อคนค้างส่งไปแจ้งใน LINE ได้ทันที |
| 🧮 **ตรวจข้อสอบ & วิเคราะห์ข้อสอบ** | ใส่เฉลย (1234 / กขคง) และคำตอบนักเรียน ได้คะแนน ค่าเฉลี่ย S.D. ค่าความยาก (p) อำนาจจำแนก (r) รายข้อ และส่งคะแนนไปหน้าคำนวณเกรดได้ |
| ⭐ **คะแนนพฤติกรรม** | ให้/หักคะแนนรายคนพร้อมเหตุผล (กำหนดเองได้) มีประวัติและย้อนกลับ ใช้ประกอบการประเมินคุณลักษณะอันพึงประสงค์ |
| 📅 **ตารางสอน** | ตารางสอนรายสัปดาห์ (ปรับเวลาคาบได้) บอกคาบที่กำลังสอน เวลาที่เหลือ และคาบถัดไป |
| 🗒️ **บันทึกหลังสอน** | บันทึกผลการจัดการเรียนรู้ ปัญหา แนวทางแก้ไข ค้นหา คัดลอก พิมพ์ทีละรายการ และส่งออก CSV เป็นหลักฐาน วPA |
| 🔳 **สร้าง QR Code** | แปลงลิงก์ (เช่น Google Form) ข้อความภาษาไทย หรือ Wi-Fi เป็น QR ใส่คำอธิบายได้ ดาวน์โหลด PNG / พิมพ์ / เต็มจอ |
| 👥 **จัดการห้องเรียน** | สร้างได้หลายห้อง คัดลอกรายชื่อจาก Excel มาวางได้ทันที สำรอง/นำเข้าข้อมูลเป็นไฟล์ |

## 🚀 เริ่มใช้งาน

### ใช้ออนไลน์
เปิดเว็บไซต์ GitHub Pages ของโปรเจกต์นี้: `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

### ใช้ในเครื่องตัวเอง
1. ดาวน์โหลดโปรเจกต์ (ปุ่ม **Code → Download ZIP**) แล้วแตกไฟล์
2. เปิดเซิร์ฟเวอร์ง่าย ๆ ในโฟลเดอร์นั้น เช่น
   ```bash
   python3 -m http.server 8000
   ```
3. เปิด `http://localhost:8000` ในเบราว์เซอร์

> ℹ️ ต้องเปิดผ่านเซิร์ฟเวอร์ (http://) ไม่ใช่ดับเบิลคลิกไฟล์ `index.html` เพราะเบราว์เซอร์ไม่อนุญาตให้โหลด JavaScript module จาก `file://`

### ติดตั้งเป็นแอป
บน Chrome/Edge กดไอคอน "ติดตั้ง" ที่แถบที่อยู่ หรือบนมือถือเลือก "เพิ่มลงในหน้าจอหลัก" เพื่อใช้แบบแอปและใช้ออฟไลน์ได้

## 💡 เคล็ดลับ
- **วางรายชื่อจาก Excel:** เลือกคอลัมน์ชื่อใน Excel/Google Sheets → คัดลอก → วางในหน้า "จัดการห้องเรียน" (ตัวเลขลำดับหน้าชื่อจะถูกตัดออกให้อัตโนมัติ)
- **ไฟล์ CSV** ที่ส่งออกเปิดใน Excel ได้ทันทีและแสดงภาษาไทยถูกต้อง
- **สำรองข้อมูลเป็นประจำ** ที่หน้า "จัดการห้องเรียน" → "ส่งออกไฟล์สำรอง" เพราะการล้างข้อมูลเบราว์เซอร์จะลบข้อมูลด้วย
- ใช้ไฟล์สำรองย้ายข้อมูลไปยังคอมพิวเตอร์เครื่องอื่นได้
- คีย์ลัด: `Space` = สุ่ม/เริ่ม-หยุดเวลา, `R` = รีเซ็ตเวลา, ในตารางเกรดกด `Enter` เพื่อเลื่อนลงช่องถัดไป

## 🌐 เผยแพร่ด้วย GitHub Pages (สำหรับผู้ดูแล)
โปรเจกต์มี workflow `.github/workflows/pages.yml` ที่ deploy อัตโนมัติเมื่อ push เข้า `main`
1. ไปที่ **Settings → Pages**
2. ที่ **Build and deployment → Source** เลือก **GitHub Actions**
3. Push เข้า `main` แล้วรอสักครู่ ลิงก์เว็บไซต์จะปรากฏในหน้า Actions/Pages

## 🛠️ โครงสร้างโปรเจกต์
เป็นเว็บแบบ static ล้วน (HTML + CSS + JavaScript module) ไม่มีขั้นตอน build และไม่มี dependency

```
index.html            หน้าหลัก
css/style.css         สไตล์ (รองรับโหมดมืด และการพิมพ์)
js/app.js             ตัวจัดการหน้า (hash router) และรายการเครื่องมือ
js/store.js           ที่เก็บข้อมูล (localStorage)
js/util.js            ฟังก์ชันช่วย (สุ่ม, เสียง, CSV, ฯลฯ)
js/tools/*.js         เครื่องมือแต่ละตัว
sw.js                 service worker สำหรับใช้งานออฟไลน์
```

### เพิ่มเครื่องมือใหม่
1. สร้างไฟล์ `js/tools/mytool.js` ที่ export object `{ id, icon, title, desc, render(el) }`
   (`render` คืนค่าฟังก์ชัน cleanup ได้ ถ้าต้องหยุด timer/ไมโครโฟนเมื่อออกจากหน้า)
2. import และเพิ่มลงใน `TOOLS` ใน `js/app.js`
3. เพิ่มชื่อไฟล์ลงในรายการ `ASSETS` ใน `sw.js` และเปลี่ยนเลขเวอร์ชัน `CACHE`
